# Bengkel Transaction Management System

Aplikasi web berbasis **Next.js (App Router)** untuk mencatat, mengelola, dan melacak riwayat transaksi perawatan kendaraan, penggantian sparepart, serta dokumentasi nota bengkel secara *real-time*.

## 🚀 Fitur Utama
- 📊 Form transaksi dinamis dengan kalkulasi otomatis (Bruto, Netto, PPN, Diskon).
- ⚙️ Sub-form list service & penggantian sparepart via Modal Window.
- 👁️ Live preview untuk setiap file/foto bukti yang diunggah sebelum disubmit.
- 💰 Auto-formatting Rupiah terintegrasi pada input form.

## 🛠️ Tech Stack
- **Framework:** Next.js 14+ (TypeScript)
- **Styling:** Tailwind CSS
